# Prerequiste
### Mathematics and Statistics
    Linear Algebra:
    Concepts like vectors, matrices, eigenvalues, and eigenvectors are foundational in ML algorithms.
    Calculus:
    Key for understanding optimization algorithms (e.g., gradient descent), especially partial derivatives and integrals.
    Probability and Statistics:
    Essential for understanding data distributions, Bayes' theorem, hypothesis testing, and statistical inference.
    Discrete Mathematics:
    Covers logic, combinatorics, and graph theory, which are important in AI algorithms like search and optimization.

### Programming Skills
    Python, R

### Data Analysis & Preparation
    Data Cleaning:
    Handling missing data, outliers, and inconsistencies in datasets.
    Exploratory Data Analysis (EDA):
    Using visualization tools (e.g., Matplotlib, Seaborn) to analyze data patterns and relationships.

### Machine Learning 
    Supervised Learning:
    Concepts like regression, classification, and evaluation metrics.
    Unsupervised Learning:
    Clustering, dimensionality reduction
    Reinforcement Learning:
    For decision-making problems (optional for beginners).

### Tools & framework
    Version Control Systems:
    Git for collaboration and version tracking.
    Machine Learning Frameworks:
    TensorFlow, PyTorch, Scikit-learn.
    Data Processing Libraries:
    Pandas, NumPy.
    Visualization Tools:
    Matplotlib, Seaborn.
    IDE
    intellij/pycharm, jupyter notebook
